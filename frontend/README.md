# ⚡ Alhaz Uddin - Portfolio Frontend

This directory contains the React 19 + TypeScript + Tailwind CSS v4 frontend for Alhaz Uddin's developer portfolio.

For complete documentation, see the [Root README](../README.md).

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
